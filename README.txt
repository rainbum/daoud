DAOUD MEMORIAL BOOK — V4.1 MUSIC
=================================

Open START_HERE.bat on Windows, or serve this folder with any static web server.

What's new in V4.1:
- Keeps the stable V4 layout and page-turn behavior unchanged.
- Adds one original, soft memorial instrumental track.
- Music is intentionally very low (7% browser volume).
- Music fades in gently after the visitor's first interaction, because browsers block audible autoplay.
- The “♫ Music on/off” button mutes/unmutes both the ambient music and page-turn sounds.

GitHub Pages ready:
- Upload the contents of this folder to the root of a GitHub repository.
- Enable Settings > Pages > Deploy from branch > main / root.
- A custom .com can be connected afterward with GitHub Pages Custom domain + DNS records.

The page-turn engine is currently loaded from jsDelivr (page-flip 2.0.7), so visitors need internet access.
